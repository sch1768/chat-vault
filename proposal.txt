# 📝 제품 기획서: ChatVault

## 1. 제품 개요 (Product Overview)

- **한 줄 정의:** ChatGPT, Gemini 등에서 나눈 귀중한 대화 기록(공유 링크)을 나만의 지식 자산으로 자동 가공·요약하고, 이를 기반으로 환각 없이 이어서 대화(RAG)할 수 있는 **AI 전용 세컨드 브레인 PWA 서비스 (ChatVault)**.
- **핵심 타겟:** 다양한 LLM을 교차 사용하며 업무, 학습, 연구를 수행하는 헤비 AI 유저 및 생산성 매니아.
- **핵심 페인 포인트 해결:**
    - 단순 공유 링크 보관의 불편함 해소.
    - 기존 엑스포터 툴의 단순 '정적 백업(TXT/PDF)' 한계 극복.
    - 대화가 길어질 때 발생하는 기존 LLM의 환각 현상을 RAG 기반 컨텍스트 제공으로 보완.

## 2. [Phase 1] MVP (최소 기능 제품) 범위

> **목표:** 핵심 가치인 '링크 접수 ➡️ 자동 요약 ➡️ RAG 추가 질문' 파이프라인의 효용성을 빠르게 검증하고 비용 및 Vercel 서버리스 호스팅 리스크를 최소화함. (개발자 본인 1인 사용 전용)
> 

### ① 주요 기능 (Core Features)

- **단일 공유 링크 접수 및 3단계 하이브리드 파싱 (ChatGPT, Gemini):**
    - [1단계 - JSON Direct Extractor]: ChatGPT 공유 링크(`chatgpt.com/share/...`)는 Vercel 백엔드에서 단순 HTTP Fetch 후 내장된 `__NEXT_DATA__` JSON 스크립트를 정규식/HTML Parser로 직접 추출하여 100% 정교한 구조화 데이터(User/Assistant 턴) 복원.
    - [2단계 - Reader/Scraper API Fallback]: Gemini 등 동적 JS 렌더링 공유 링크(`share.gemini.google/...`)나 보안 차단 링크는 Jina Reader API (`https://r.jina.ai/`) 또는 Firecrawl API를 우회 경유하여 마크다운 텍스트로 안전하게 파싱.
    - [3단계 - 수동 붙여넣기 Fallback UI]: 봇 차단 또는 비공개 링크 파싱 실패 시를 대비해 대화 마크다운/텍스트를 직접 붙여넣을 수 있는 수동 입력 탭 지원.
- **Vercel 타임아웃 방어형 3단계 비동기 처리 & 자동 요약:**
    - Vercel Serverless Function 10초 타임아웃 방지를 위해 파싱 ➡️ 요약(Gemini) ➡️ RAG 임베딩 과정을 API 분리 및 프로그레스 바 UI(30% ➡️ 60% ➡️ 100%)로 비동기 안내.
    - Gemini API (`gemini-2.5-flash` 또는 `gemini-1.5-flash`)를 활용해 대화 전체 맥락 분석 후 제목 자동 생성, 3줄 핵심 요약, 관련 카테고리 태그(#코딩, #여행 등) 자동 추출.
    - 결과 화면에서 유저가 제목이나 태그를 수동으로 수정(Manual Override)할 수 있는 가벼운 편집 UI 제공.
- **지식 대시보드 및 저장된 대화 관리 UI/UX:**
    - **카드 대시보드 뷰:** 저장된 대화 목록(제목, 생성일, 태그, 3줄 요약) 시각화.
    - **태그 필터 & 키워드 검색:** 태그 클릭 시 해당 태그 대화만 즉시 필터링 및 제목 검색 기능.
    - **대화 상세 & RAG 채팅 인터페이스:** 대화 원본 마크다운 뷰어 + 우측/하단 대화 이어가기(RAG) 채팅창 제공.
- **RAG 기반 '추가 질문 및 이어가기':**
    - 저장된 대화 텍스트를 문단 단위(Chunk)로 쪼개어 임베딩(`text-embedding-004`) 후 벡터 DB에 저장.
    - 해당 저장본 내에서 추가 질문을 던지면, 관련 맥락(Context)만 쏙 뽑아 Gemini 프롬프트에 주입하여 환각과 비용을 최소화한 정확한 답변 제공.
- **증분 업데이트형 대화 버전 관리 (Incremental Append):**
    - 유저가 이미 저장한 대화방의 링크를 나중에 다시 공유하면, 중복 생성하지 않고 `Message ID` 또는 `hash(질문+답변)` 기준으로 **새로 추가된 대화 턴(Turn)만 파싱하여 뒤에 덧붙임**.
    - 추가된 데이터만 벡터 DB에 신규 인덱싱하고, 요약본은 기존 요약에 새 맥락을 반영하여 저비용으로 업데이트.
- **모바일/데스크톱 기본 PWA 설정:**
    - Web App Manifest (`manifest.json`) 및 서비스 워커를 적용하여 '홈 화면에 추가 (App 설치)' 및 Full-screen Standalone 모드 지원.

### ② 대용량 파일 RAG 방어 파이프라인 (MVP 버전)

- **AI의 텍스트화된 설명 활용:** 유저가 첨부한 대용량 파일이나 이미지 자체는 RAG 임베딩 대상에서 과감히 제외. 대신 대화 속에서 AI가 해당 파일을 설명하거나 답변한 '텍스트 맥락'만 벡터 DB에 저장하여 비용과 속도를 모두 방어.
- **유저 안내 UI:** RAG 채팅창 및 결과 화면에 *"⚠️ 용량이 큰 일부 첨부파일 내부 텍스트는 추가 질문(RAG) 검색 대상에서 제외되었습니다. (대화 맥락은 유지됨)"* 문구의 툴팁/안내 가이드 노출.
- **멀티모달 URL 보존:** 이미지나 파일의 원본 URL 링크는 요약본 내에 `[첨부파일]` 형태로 보존하여 유저가 시각적으로 참고할 수 있게 앵커링.

### ③ 기술 스택 (Tech Stack - Vercel 단일 배포 최적화)

- **프론트엔드/백엔드 통합:** Next.js (App Router, PWA 설정 포함, TypeScript, Tailwind CSS + shadcn/ui)
- **LLM & Embedding:** `@google/genai` (Gemini API Key는 Vercel 환경변수로 설정)
- **데이터베이스 & Vector Store:** Supabase (PostgreSQL + pgvector 확장팩) 또는 Vercel Postgres / Turso / Upstash

## 3. [Phase 2] 앞으로 발전할 내용 (정식 출시 및 고도화)

> **목표:** 지인/다자간 공유를 위한 보안 인증 도입, 외부 생산성 생태계와의 연결을 통해 락인(Lock-in)을 강화하고 비즈니스로서 자립함.
> 

### ① 보안 인증 & 사용자 관리 (Authentication)

- **접근 제어 및 회원가입:** 
    - 지인 및 멀티 유저 사용을 위한 Supabase Auth (Google 소셜 로그인) 및 허용된 이메일 도메인/유저 접근 제어 추가.

### ② 유저 커스텀 가공 옵션 및 외부 연동 (Integration)

- **입맛대로 커스텀 설정 모달(Modal) 제공:**
    - 요약의 깊이 조절 (간결한 3줄 요약 vs 상세 분석형).
    - 어조 및 말투 세부 선택 (개발자용 ~음체, 비즈니스 보고서용 ~습니다체 등).
- **원클릭 노션(Notion) 및 옵시디언(Obsidian) 자동 전송:**
    - 노션 공식 API(OAuth 2.0)를 연동하여, 가공된 요약본과 태그를 유저의 노션 데이터베이스 속성에 맞춰 깔끔한 토글/마크다운 형태로 자동 삽입.

### ③ 모바일/PC 환경 UX 극대화

- **모바일 Web Share Target API 적용:** 스마트폰의 기본 [공유하기] 창에서 내 PWA 앱을 바로 선택해 복사-붙여넣기 없이 원터치로 대화 접수.
- **PC용 크롬 확장 프로그램(Chrome Extension) 출시:** 대화창 내에 버튼 하나만 누르면 백그라운드로 공유 링크를 자동 생성해 내 서비스로 전송하는 원클릭 스크랩 환경 제공.

### ④ 유료화 모델 및 파일 RAG 해제 (Monetization)

- **수익화 모델 도입:** 악성 유저의 API 체리피킹을 방지하기 위해 라이트 유저에게는 월간 요약/질문 쿼터 제한 제공. 초과 사용 시 구독제 또는 개인 API Key 입력 유도.
- **[유료 버전 전용] 프리미엄 파일 RAG 기능 해제:** 유료 구독 유저에 한해, MVP 때 제외했던 **'첨부파일 내부 텍스트(ex. 수십 페이지짜리 긴 PDF 기획서, 논문 등)를 온전히 RAG 시스템에 포함하여 심층 질문할 수 있는 기능'** 구현 및 해제.

## 4. 결론

이 기획서는 라이트 유저에게는 '직관적이고 편리한 대화 저장소'를 제공하고, 헤비 유저에게는 **'내 메모장(노션 등)으로 데이터를 정제해 쏴주는 스마트 허브'** 역할을 하여 양쪽 시장을 모두 만족시킬 수 있는 구조를 취하고 있습니다. 특히 MVP 단계에서 개발자 1인 사용에 맞춰 보안 인증 복잡도를 줄이고, Vercel 호스팅 환경에 최적화된 단일 기술 스택, 3단계 비동기 처리 파이프라인, 지식 대시보드 UI/UX 및 기본 PWA 설정을 완비했습니다.
